# Every link

Base: <https://ysetbon.github.io/Scoubidou3D/>

Published from `main` by `.github/workflows/deploy.yml`, so these are live as soon as a
change lands there. Paths are relative to the base above.

## The three pages

| Page | Link | What it is |
| --- | --- | --- |
| Project site | [`/`](https://ysetbon.github.io/Scoubidou3D/) | The written project: what it is, how the weave works, the thirteen samples |
| The studio | [`/app/`](https://ysetbon.github.io/Scoubidou3D/app/) | The editor itself — orbit, edit, weave, save |
| Level gallery | [`/levels/`](https://ysetbon.github.io/Scoubidou3D/levels/) | Every level of every m×n face, rendered. Opens on 1×5 |

### Sections of the project site

- [`/#samples`](https://ysetbon.github.io/Scoubidou3D/#samples) — the thirteen built-in scenes, each card linking straight into the studio
- [`/#how`](https://ysetbon.github.io/Scoubidou3D/#how) — from flat idea to woven object, in three steps
- [`/#translate`](https://ysetbon.github.io/Scoubidou3D/#translate) — the translation from OpenStrand, term by term
- [`/#lab`](https://ysetbon.github.io/Scoubidou3D/#lab) — the interactive proof — flatten the weave and tip it back
- [`/#learn`](https://ysetbon.github.io/Scoubidou3D/#learn) — the notes: geometry, control points, levels
- [`/#run`](https://ysetbon.github.io/Scoubidou3D/#run) — running it yourself

## Two things worth knowing

- **The theme is shared.** The site and the studio store one choice, so opening one from
  the other keeps the lights as you set them. `?theme=light` / `?theme=dark` forces it.
- **An unknown `?sample=` is ignored** rather than erroring, so a stale bookmark still
  lands you in a working studio.
