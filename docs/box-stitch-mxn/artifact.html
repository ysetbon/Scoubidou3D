Box Stitches

A box stitch begins from exactly the same starting stitch as a twist. The difference is k = 0: every loose end pairs with the end straight across from it, so each arm simply carries on along its own line and back over the block. Nothing rotates, nothing is stretched — the finished stitch is the weave doubled and squared off, a closed box. All sixty-four faces from 1×1 to 8×8 are drawn here, in both hands.

Anatomy 3 × 2, left hand

How a strand is named

3_2set 3, layer 2 — set = one ribbon, layer = which piece of it _1the first piece, buried inside the block _2 / _3the two arms leaving the block, one each side _4 / _5the continuation: _2 carries on as _4, _3 as _5 3_2_1_3a mask — 3_2 passes over 1_3

Which set is which

1 … nthe horizontal sets (n of them) n+1 … n+mthe vertical sets (m of them)

In m × n, m counts the vertical ribbons and n the horizontal ones — so 3 × 2 is three verticals crossing two horizontals.

Because _4 is collinear with _2 and _5 with _3, each ribbon reads as one straight bar that runs clean across the block and sticks out on both sides. Every bar crosses every ribbon of the other direction a second time, which is where the second layer of masks comes from.

How one is made the same passes as a twist — the last one has nothing to do

01

Weave the block

Lay m vertical ribbons across n horizontal ribbons and mask the crossings. That's the starting stitch.

02

Pair by k = 0

The pointer doesn't move: every end pairs with the end straight opposite, so each arm aims along its own line.

03

Carry on straight

_2 → _4, _3 → _5, each continuing back across the block and out the far side.

04

Mask again

The block's over/under pattern is repeated one-for-one on the new crossings, on top of the starting stitch.

Step 5, align, is a no-op at k = 0. Both passes return immediately with preserve_continuation and the message "k=0: _4/_5 alignment matches continuation exactly, no adjustment needed". That was confirmed on the eight runs the first version of this sheet was built from — and it cannot be otherwise at any size, because the aligner's job is to bring the arms of a group to a shared angle, and at k = 0 every arm of a group already lies on its family's axis. That is the whole difference from a twist, where the arms must be rotated to a shared angle and stretched until the gaps even out.

The rules everything on this page follows from these

// sets
horizontal sets = 1 … n , vertical sets = n+1 … n+m

// directions — the only thing the hand changes
horizontal _4 → 0° (right) , _5 → 180° (left) // both hands
vertical LH _4 → +90° (down) , _5 → −90° (up)
vertical RH _4 → −90° (up) , _5 → +90° (down)

// lengths of the continuation bars
horizontal bar = 112·m + 60 px , vertical bar = 112·n + 60 px
box footprint = 112·(m+1) × 112·(n+1) px

// how many strands
base 3(m+n) + base masks 2mn + continuation 2(m+n) + continuation masks 2mn
total = 5(m+n) + 4mn

Left hand · cw

x_4→horizontal arms run right x_5←horizontal arms run left x_4↓vertical arms run down x_5↑vertical arms run up

Right hand · ccw

x_4→horizontal arms run right x_5←horizontal arms run left x_4↑vertical arms run up x_5↓vertical arms run down

The hand also swaps which row each horizontal bar sits on — that's the _2/_3 swap — so the RH box is the mirror of the LH box, exactly as with twists. The mask lists are identical in both hands: every vertical x_2 over every horizontal y_3, every x_3 over every y_2, then the same pattern again on the _4/_5 layer.

A face is square only when m = n, and those are the only ones whose two bars are the same length: m sets the width and n the height, so 8 × 1 is a wide strip and 1 × 8 is a tall one. Strand count grows as 4mn — an 8 × 8 box is 336 strands against a 1 × 1's 14.

Box or twist same start, k decides

k = 0 — box. Pointer doesn't move, arms carry on straight, alignment does nothing. The result is fixed: angles are always 0° / 180° / ±90°, lengths are always 112m + 60 and 112n + 60. There is exactly one box per size per hand.

k ≠ 0 — twist. The pointer walks the rim, so every end aims somewhere else, the two groups fan out, and the aligner has to pick a shared angle per group and stretch the arms until the gaps are equal (never below strand width + 10 = 56 px). Those angles, sizes and drawings are in the companion sheet, Twist Stitches.

The first version of this sheet drew four sizes — 1×1, 2×1, 3×2, 3×3 in both hands — straight out of mxn_{lh,rh}_continuation.generate_json(m, n, k=0, direction) and the alignment pass that follows it. The drawings here are laid out by the page itself from the rules above, and for those eight stitches they come out identical to the generated ones, character for character; the other 120 are the same construction carried on.
Real coordinates, widths and mask order throughout (block → block masks → continuation → continuation masks). Set colours are the one thing not carried over: the original generator randomises them past the second set, so this sheet fixes a palette — horizontal sets by index, vertical sets along one indigo ramp — and keeps it the same at every size.
