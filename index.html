A 3D reimagining of OpenStrand Studio

See every strand.
Shape every crossing.

OpenStrand draws laces from the top down and fakes over-and-under with masking. Scoubidou3D gives every strand a real thickness, turns its layer index into a height, and turns each mask into a crossing where one lace physically lifts and the other dips — so you can tilt the camera and watch the weave interlock.

Two of them are worth putting side by side. Box stitch — 10 levels and round stitch — 10 levels are the same four folds, the same square, the same one mask a round and the same 42 strands — the only difference is that the box stitch reverses its rotation each round and the round stitch does not. One bit, and the column changes rhythm: the box stitch repeats every two rounds and bands in pairs, the round stitch repeats every round and runs straight. It is in the two thumbnails above.

Two of sixty-four

The box stitch,
on any face.

The box stitch is not only the square one. Lay m ribbons across n and the same move works any face from a 1×1 to an 8×8 — the twist family's own starting stitch with the twist taken out, so nothing rotates, nothing is stretched and there is exactly one box per size per hand. All 64 are in the studio in both hands; work one round after another and it rises as a column.

From flat idea to woven object

Your pattern finally
makes sense in space.

Wherever two centerlines cross, the app knows who is over: a mask if one covers the pair, otherwise the higher layer. Each strand turns its crossings into a smooth height field, and the ribbon is swept along that undulating centerline.

The translation, in one move

Give a strand a thickness.
Everything else follows.

Each strand becomes a ribbon, like the plastic-lacing lanyards this is named after: its OpenStrand width runs across the ribbon, a new thickness runs through it, and its layer index becomes its height.

A crossing sets an absolute height, not a nudge

The over lace goes to +h and the under lace to −h about the weave plane. A mask therefore means one purely local thing — this strand crosses over that one, here — and costs the same whether the two are neighbours in the layer panel or ten layers apart. Masking the bottom strand over the top one leaves every other layer untouched.

Overlapping crossings blend, they don't add

Where two crossings fall close together the heights are pulse-weighted-averaged, so neighbours pulling opposite ways resolve instead of cancelling or doubling. The three-way case falls out for free: the top lace lands at +h, the bottom at −h, and one caught between them settles in the middle.

Because each crossing is resolved on its own, cyclic weaves work — x over y, y over z and z over x is impossible for a rigid stack, but it is exactly what a real woven knot does.

If you want the detail

Four notes,
written from the code.

Each one is a short document in the repository, illustrated with the same samples above. They exist because these four ideas are where the 3D version stops being a rendering trick and starts being a model of a real stitch.

01 · Layer levels

Storeys in the stack

A level break makes everything above it rest a full storey higher — two strand thicknesses, the height of a woven round — so a lace sits on the round below instead of through it.

Read the note
02 · Control points

The curve, faithfully

The centerline is a port of OpenStrand's own eased two-segment curve, with the same marks and the same staging — which is why an imported file keeps its shape.

Read the note
03 · The box stitch

Nine crossings, one mask

The arms are folded in layer order, so the stacking already tells the truth at eight of the nine crossings. The ninth is the move that locks the stitch.

Read the note
04 · The twist stitch

A face that turns

Three laces on a 2×1 face, 26° further round every stitch. Grown from a stitch built by hand rather than derived — an idealised one reaches every fold the same and comes out a cylinder.

Read the note

Made for play.
Built with precision.

✦

Real thickness

Every strand is extruded into a solid ribbon with configurable thickness, rounded edges, rounded ends and a stroke-coloured outline.

⌁

Faithful curves

Import an OpenStrand Studio or OpenStrandJS .json save and see familiar shapes in 3D. The curve math is a port of the original.

◉

Private by default

The editor runs locally in your browser. Saved samples go to local storage; nothing is uploaded anywhere.

Run it yourself

A link, not
a download.

The quickest path is the hosted build — open the app and start orbiting. To hack on it you need Node.js 18 or newer.

Develop

git clone https://github.com/ysetbon/Scoubidou3D.git
cd Scoubidou3D
npm install
npm run dev      # http://localhost:5173

Build & reshoot

npm run build    # site at /, app at /app/
npm run shots    # reshoot site/shots/*.webp

npm run shots drives the running app and screenshots every picture on this page — both themes — from the real 3D canvas, so a sample cannot drift away from its own photograph. Needs npm run dev up in another shell.
